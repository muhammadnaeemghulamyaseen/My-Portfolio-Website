# 🧑‍💻 Personal Portfolio Website

A professional, interactive **Personal Portfolio Website** built using **Streamlit**. This application showcases my background, education, technical skills, projects, and contact information through an intuitive multi-page sidebar interface.

This project highlights how data science workflows, machine learning models, and personal achievements can be turned into a clean, interactive web application.

---

## ✨ Features

- **Multi-Page Navigation:** Easily switch between Home, About Me, Projects, Skills, and Contact pages using a sidebar menu.
- **Project Showcase:** Highlights major projects along with their descriptions, source code repositories, and live links.
- **Structured Skill Catalog:** Categories detailing programming languages, data science tools, machine learning capabilities, and APIs.
- **Clean Layout:** Responsive design featuring a profile image container and clean typography.

---

## 🛠 Technologies Used

- **Python** 🐍
- **Streamlit** (Web framework)
- Python Conditional Statements (for page routing)

## ⚙️ Installation & Setup

### 1. Clone the Repository
```bash
git clone https://github.com/muhammadnaeemghulamyaseen/My-Portfolio-Website
```

### 2. Navigate to the Project Directory
```bash
cd My-Portfolio-Website
```

### 3. Create a Virtual Environment
```bash
python -m venv venv
```

Activate the environment:
- **Windows:** `venv\Scripts\activate`
- **macOS/Linux:** `source venv/bin/activate`

### 4. Install Dependencies
Create a `requirements.txt` file and add `streamlit` to it, then run:
```bash
pip install -r requirements.txt
```

---

## 🚀 How to Run

Launch the application locally with the following command:
```bash
streamlit run app.py
```
Streamlit will open the application automatically in your default web browser.
